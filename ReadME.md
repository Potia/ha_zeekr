Интеграция подключается к **неофициальному API Zeekr** (тому же, что использует мобильное приложение), авторизуется по SMS и каждые 60 секунд забирает состояние автомобиля: батарея, зарядка, климат, двери, окна, панорама, GPS и многое другое. Никаких удалённых команд — только чтение.

## ✨ Что умеет

| | |
|---|---|
| 📊 **58 сенсоров** на автомобиль | батарея, запас хода, зарядка DC/AC (мощность, ток, время), шины, жидкости, PM2.5 салон/улица, климат, парковка, координаты, режим охраны |
| 🔐 **17 бинарных сенсоров** | двери, окна, багажник, капот, шторки панорамы, GPS, торможение, рекуперация |
| 📍 **device_tracker** | позиция в градусах; без GPS — `unknown`, а не точка в океане |
| 🔄 **кнопка Refresh** | принудительный опрос по требованию |
| 🛡 **режим охраны** | честный статус из `theftNotification`, отдельно автодальний (AHBC) |

## 📦 Группы сущностей

<details>
<summary>Полный список групп — нажми, чтобы развернуть</summary>

- **Батарея** — заряд %, запас хода, температура батареи, 12V
- **Зарядка DC** — статус, мощность, напряжение, ток, время до полного, состояние коннектора
- **Зарядка AC** — статус, мощность (V×I), время
- **Движение** — скорость, ускорение, торможение, рекуперация, парковка (сколько стоит)
- **Шины** — температура и давление каждого колеса
- **Обслуживание** — уровни тормозной/омывающей жидкостей, антифриза
- **Воздух** — PM2.5 салон/снаружи, влажность, уровень загрязнения
- **Климат** — заданные температуры, состояние кондиционера и сидений
- **Безопасность** — 4 двери, 4 окна, багажник, капот, режим охраны, автодальний
- **Панорамная крыша** — шторки переда/зада, степень прозрачности
- **Координаты** — широта/долгота/высота/направление, статус GPS
- **Служебное** — время последнего обновления, VIN, тип кузова

</details>

## 🚀 Установка

### HACS (рекомендуется)

1. **HACS → Интеграции → ⋮ → Пользовательские репозитории** → добавить `https://github.com/Potia/ha_zeekr` (тип: *Integration*)
2. Найти **Zeekr Vehicle Integration** → **Установить**
3. Перезагрузить Home Assistant

### Вручную

Скопировать `custom_components/zeekr/` из [последнего релиза](https://github.com/Potia/ha_zeekr/releases) в `<config HA>/custom_components/zeekr/` и перезагрузить HA.

## ⚙️ Настройка

1. **Настройки → Устройства и службы → Интеграции → Добавить → Zeekr**
2. Телефон — китайский номер из приложения Zeekr в формате `138xxxxxxxx`
3. Ввести код из SMS — интеграция сама получит и сохранит токены

> [!NOTE]
> Токены живут в config entry HA. При их протухании интеграция замолчит — поможет повторная настройка (переавторизация по SMS).

## ⚠️ Ограничения и дисклеймер

- API **неофициальный** — Zeekr может изменить его в любой момент, интеграция тогда догоняет
- Требуется **китайский номер** из приложения Zeekr (SMS-авторизация)
- Только чтение: запуск климата, замки и прочие команды не реализованы — сознательное решение, безопасность важнее
- Автор не связан с Zeekr/Geely; использование на свой риск
